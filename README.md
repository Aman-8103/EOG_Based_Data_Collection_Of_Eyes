## 📌 Executive Summary

> [!NOTE]
> **Repository Scope:** This repository contains the **Phase 1: Hardware Interfacing, Visual Stimulus Tracking, and Automated Ground-Truth Labeling Engine**. 
> The collected and verified dataset curated here is engineered to train machine learning & deep learning classification models (Phase 2) for multi-directional robotic and assistive control.

**iSync** utilizes the corneal-retinal electrical dipole potential (~0.4 – 1.0 mV) generated by human eye movements. By capturing microvolt changes across horizontal and vertical axes, the system provides high-fidelity directional data (**LEFT**, **RIGHT**, **UP**, **DOWN**, **REST / CENTER**) to enable hands-free interaction for patients with motor neuron diseases (e.g., ALS), quadriplegia, or spinal cord injuries.

## 🚀 Key Highlights & Features

- ⚡ **Dual-Channel High-Speed Acquisition:** Captures simultaneous Horizontal (CH1) and Vertical (CH2) channels at **250 Hz** over high-speed serial (115200 baud).
- 🎮 **Dynamic Neon Stimulus Interface (`index.html`):** Smooth 60 FPS HTML5 Canvas with neon ball animations, audio cues, and synchronized countdowns.
- 🔄 **Dual Engine Architecture:**
  - **Live Hardware Stream:** Real Arduino R4 WiFi + EXG Pill serial connectivity.
  - **Mock Hardware Generator:** Synthetic dual-channel EOG waveform generator for testing without physical electrodes.
- 🏷️ **Automated Ground-Truth Label Mapping:** Deterministic phase timelines automatically map raw EOG samples into `REST`, `RIGHT`, `LEFT`, `UP`, and `DOWN` without human annotator bias.
- 🛡️ **Built-in Quality Verification Suite (`verify_dataset.py`):**
  - Sample index continuity (starts from 1 per attempt).
  - Independent duration tracking (starts from 0.000s).
  - Monotonicity checks & NaN/numeric validation.
  - Strict Quality Control: **SELECT**, **REJECT**, or **RECORD AGAIN**.
- 📈 **Instant Visual Diagnostics (`eog_plotter.py`):** Generates dual-channel trajectory plots per recording trial for instant physical validation.

| **Lead Wires** | DIN 1.5mm Snap Electrodes Cables | Shielded signal transmission |

### 2. Clinical Electrode Placement Montage

```
                       [ REF / GND ]
                         (Forehead)
                             |
                   [ UP ]    |
                 (Above Eye) |
                             |
     [ LEFT ] ------ ( EYE ) | ( EYE ) ------ [ RIGHT ]
    (Left Temple)            |               (Right Temple)
                             |
                  [ DOWN ]   |
                 (Below Eye) |
```

- **Channel 1 (Horizontal):** Left Temple (+) to Right Temple (-).
- **Channel 2 (Vertical):** Above Eye (+) to Below Eye (-).
- **Reference / Ground:** Mid-forehead or earlobe (clean neutral reference).

## ⏱️ Stimulus Sequences & Trial Protocol

A standard recording trial runs for **24.0 seconds** divided into **12 deterministic phases** (2.0 seconds per direction):

```
Time (s) : 0.0s ---- 2.0s ---- 4.0s ---- 6.0s ---- 8.0s ---- 10.0s ---- 12.0s ---- 24.0s
Direction: [ REST ] [ RIGHT ] [ LEFT ]  [ REST ] [  UP  ]  [ DOWN ]  [ REST ] ... [ END ]
```

| Phase Index | Window (s) | Target Direction | Stimulus Ball Position | Expected EOG Delta |
| :---: | :---: | :---: | :---: | :---: |
| **Phase 1** | 0.0s – 2.0s | `REST` | Screen Center | Baseline potential (0 mV) |
| **Phase 2** | 2.0s – 4.0s | `RIGHT` | Extreme Right | CH1 Positive deflection |
| **Phase 3** | 4.0s – 6.0s | `LEFT` | Extreme Left | CH1 Negative deflection |
| **Phase 4** | 6.0s – 8.0s | `REST` | Screen Center | Return to Baseline |
| **Phase 5** | 8.0s – 10.0s | `UP` | Screen Top | CH2 Positive deflection |
| **Phase 6** | 10.0s – 12.0s | `DOWN` | Screen Bottom | CH2 Negative deflection |

## 🛠️ Quickstart & Usage Guide

### 1. Prerequisites
Ensure **Python 3.10+** is installed on your workstation. Install required dependencies:

```bash
pip install pyserial pandas numpy matplotlib
```

### 2. Launch Data Collection Engine
Run the primary engine from the terminal:

```bash
python collector.py
```

- If an Arduino UNO R4 WiFi is connected, it auto-detects the serial COM port (115200 baud).
- If no hardware is detected, it seamlessly falls back to **Mock Hardware Mode** for dry-run simulation.

### 3. Open Ball Tracking Interface
Open your web browser and navigate to:
```
http://localhost:8000
```
- Enter **Subject ID** (e.g., `S01`) and **Attempt ID** (e.g., `A01`).
- Click **START TRIAL**. A 3-2-1 audio-visual countdown will initiate.
- Direct the subject to keep their head still and track the moving neon ball with their eyes only.

### 4. Review & Curate Trial
Upon 24s completion:
- Inspect the generated dual-channel signal plot.
- Click **ACCEPT / SELECT** to commit the trial to `LabelData/Eog Data.csv`.
- Or click **REJECT / RECORD AGAIN** if blink or motion artifacts are observed.

### 5. Run Verification Test Suite
To verify the complete research workflow integrity:
```bash
python verify_dataset.py
```
